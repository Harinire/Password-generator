Password Generator

The Password Generator is a Python-based desktop application developed using the Tkinter library. It helps users create strong and secure passwords by allowing them to customize the password length and choose whether to include uppercase letters, lowercase letters, numbers, and special characters.

The application also evaluates the strength of the generated password, provides a one-click copy-to-clipboard feature, and allows users to save generated passwords for future reference. Its simple and user-friendly graphical interface makes it suitable for beginners while demonstrating practical Python programming concepts such as GUI development, event handling, file operations, and secure random password generation.

Features

- Generate secure random passwords
- Customize password length
- Include/exclude uppercase, lowercase, numbers, and symbols
- Password strength indicator
- Copy password to clipboard
- Save generated passwords to a text file
- Simple and easy-to-use graphical interface

Technologies Used

- Python
- Tkinter (GUI)
- Random Module
- String Module

This project is designed to improve password security by generating strong, unpredictable passwords and serves as a beginner-friendly Python application for learning GUI development and basic cybersecurity concepts.
